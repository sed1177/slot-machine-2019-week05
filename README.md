# Slot Machine

A web application that lets the user play a Slot Machine game. If the user gets 2 matches, they will be awarded $250  to their balance for each win! IF they user gets all cards matched, they will be awared $500!
<br>

## Tech Stack
- **Frontend:** HTML, CSS, and JavaScript.
